# 0002 — CTA: jujur pre-launch, tanpa link mati

Semua call-to-action di landing page harus jujur tentang status Finesa.
Badge "Segera Hadir" menggantikan semua tombol download, masuk, dan store.
Tidak ada link yang mengarah ke halaman kosong atau sistem yang belum ada.

Alternatif yang ditolak: form daftar tunggu (butuh infra), link WhatsApp
(kurang profesional), tombol non-interaktif "Segera" (tetap mengecoh).

Konsekuensi: conversion path lemah sampai app benar-benar ada.
Tapi ini lebih baik daripada mengecoh pengguna dengan link mati.
